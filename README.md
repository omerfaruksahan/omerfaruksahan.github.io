# omerfaruksahan.github.io

The developer website for Read Fast.

- `app-ads.txt` authorises Google AdMob to sell the ads in Read Fast
  (the IAB app-ads.txt standard). AdMob looks for it at the root of the
  developer website named in the app's store listings, which is why it lives
  here and not in the privacy policy's repo.
- `index.html` is the homepage.

The privacy policy has its own repo, `PRIVACY-FastReaders`, served at
<https://omerfaruksahan.github.io/PRIVACY-FastReaders/>.
